# Example patches

Open a patch in the desktop app with `CmdOrCtrl+O`, or in the terminal with:

```sh
orca-seaflake patches/orcaDronePulse1.orca
```

Press `Space` to play. You'll need a MIDI output selected to hear anything (see [Connect it to a synth](../README.md#connect-it-to-a-synth)).

| File | What it is |
| --- | --- |
| `orcaDronePulse1.orca` | Small patch: random (`R`), write (`X`) and increment (`I`) |
| `orcaforMWM23rd.orca` | Larger patch, 60 rows |
| `orca-24O02-477412.orca` | Clocks, delays and random values feeding each other |
| `untitled-1793571007565.orca` | Random values driving track (`T`) and write (`X`) |

## Songs

Song files for [Song Mode](../docs/SONG_MODE.md). Open one from Song Mode with `I` (import), in either the desktop app or the terminal.

| File | Format |
| --- | --- |
| `songs/testingsequencing1.song` | Current format (LEN × MUL) |
| `songs/untitled2.song` | Oldest format (bars + 16ths), converted when opened |
| `songs/testingsongmode-26V04-811047.orca-song` | Early Song Mode build format, converted when opened |
